# Decisions

Why Chat is built the way it is. Newest first; a row changes only when the decision does.

| Date   | Decision                                                                                                                                                                                                                            | Why                                                                                                                                                                                                       |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nov 25 | Deploys by hand with `pnpm deploy` (build, migrate, deploy) until step 6 moves them to CI. `/setup` is turned off by replacing `SETUP_CODE` with a random one nobody knows, not by deleting it                                      | Nothing to automate yet, and no Cloudflare token in GitHub until then. `SETUP_CODE` is a required secret, and Wrangler refuses to deploy a Worker missing one                                             |
| Nov 25 | Sign-in: Better Auth's passkey plugin on D1 through Better Auth's own D1 support. The first passkey needs a one-time `SETUP_CODE` secret on `/setup`; Dev signs in with a button that exists only with `DEV_SIGN_IN=1` on localhost | Drizzle waits for the chat list, the first thing that needs it. No passwords means nothing to hash on the server (10 ms CPU), and the code lives in the URL fragment, so it never reaches the logs        |
| Nov 25 | Each piece comes in with the feature that needs it: styles, DESIGN.md notes, docs and tools for parts not built yet stay in the archived Chat until then                                                                            | Alec: simple first. A scaffold carrying 18,000 lines of other things was hard to review and kept files nothing used                                                                                       |
| Nov 25 | The repo is public, with secret scanning and push protection; secrets live only in Wrangler and GitHub secrets                                                                                                                      | Nothing secret is in the code, and GitHub's runners are free and unlimited for public repos                                                                                                               |
| Nov 25 | CI runs on GitHub's runners, not the home server                                                                                                                                                                                    | Nothing of this app runs at home any more, and a public repo on a self-hosted runner would let anyone's PR run code there                                                                                 |
| Nov 25 | pnpm 12 with `minimumReleaseAge` 7 days and `allowBuilds`                                                                                                                                                                           | Same supply-chain wait as before (npm's `min-release-age`), in pnpm's own settings. `core-js-pure`'s install script only prints a banner, so it's denied                                                  |
| Nov 25 | Agents SDK routes go in a custom server entry beside TanStack Start's handler (`routeAgentRequest(…) ?? handler.fetch(…)`)                                                                                                          | Proven in a spike on Nov 25: a WebSocket to an Agent echoed in dev, and the build carried the Durable Object. The Agents SDK adds about 2.4 MB (550 KB gzipped) to the Worker, inside the free 3 MB limit |
| Nov 25 | Rebuilt from scratch on Cloudflare's free plan: TanStack Start on Workers, ui-sdk and Tailwind 4, AI SDK on NVIDIA, the Agents SDK (`AIChatAgent`) for chats, D1 with Drizzle, Better Auth passkeys                                 | $0 and no server at home. The first Chat (Next.js, SQLite on the home server) is archived; its chats aren't carried over. Fallback if TanStack Start is shaky: React Router 7                             |
