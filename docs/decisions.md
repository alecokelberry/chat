| Nov 26 | e2e tests take `test` from `e2e/session.ts`, which fails a test whose page throws, logs an error or logs a `[ui-sdk]` warning; lint stops a spec importing Playwright's own. | Nov 26 | Each isolate's one-time work happens at startup or not at all: `src/server.ts` also builds cn's class-name tables, Better Auth's runtime schema check is off (`validateSchema: false`), and a path with a file extension that reaches the Worker gets a bare 404 instead of the rendered 404 page                                                                                                                                                                                               | Live traffic is light, so nearly every request is its isolate's first: they ran 20-270 ms of CPU against the free plan's 10 ms (no 1102 errors yet, but Cloudflare stops a Worker that goes over consistently). | Nov 26 | The chat list is a D1 table, `chat`, read and written through Drizzle; drizzle-kit (dev only, `pnpm db:generate`) writes its migrations from the Drizzle table, and Wrangler applies them as before. The chat's agent writes its row (a send moves it up, the first reply's title from Lightning) and tells its open tabs, which reload the list. Signed-in pages share a layout route, `_app`, that loads the list; it groups by day only in the browser. The phone sidebar is ui-sdk's Drawer | Drizzle came with the first table that needed it, and drizzle-kit is its standard D1 setup: one source for the schema, so the table and its SQL can't drift. Alec prefers best-practice libraries that save code. The agent already holds the user and the chat, and its CPU isn't the Worker's 10 ms. The server doesn't know Alec's time zone. The archived Chat dropped the Drawer for a slid Dialog when it lagged on the iPhone; the spec asks for the Drawer, so it gets a fresh try on the phone before anything is ported |
| Nov 26 | The model picker is a popover on desktop and a sheet on phones (`presentation="auto"`). The sheet keeps only ui-sdk's own translate as motion, with no shadow, fade or blur of ours                                                                                                                                                                                                                                                                                                             | Alec, after trying the popover: a sheet on phones. Replaces the Nov 26 "stay popovers on phones" row. | Nov 25 | A reply that NVIDIA refuses with a 429 or 503 is retried once by the AI SDK (`maxRetries: 1`, 2 s backoff), then ends with a quiet line in the thread saying why, with Retry. Never a fallback model                                                                                                                                                                                                                                           | Alec chooses the model; a silent switch would surprise him. One retry covers a brief spike without doubling the load on a 40-a-minute limit. The AI SDK already retries before a stream starts, so there's no retry code of our own. Replaces the archived Chat's two retries and fallback                                                                                                                                                                                                                                        |
| Nov 26 | The chat screen ports the archived Chat's own parts and measurements instead of approximating them: the thread opens at your last message and brings each new one to the top, with a jump-to-latest button (`MessageScroller`, replacing `ScrollArea` stuck to the end); a waiting marker until the first word; the composer's 58px pill and 32px Send; a tap never rings it (`FocusModality`)                                                                                                  | Alec: it should feel like the app he had. | Nov 26 | The model picker, and menus generally, stay popovers on phones: no `presentation="auto"` sheet. | Nov 25 | Each message carries the model it was sent with in its metadata (`{ model: "ultra" }`); the agent answers with the model the last message names, checked against the model map in `src/lib/ai/models.ts` (Super for anything else), and the picker reopens a chat on it                                                                                                                                                                                                                         | Nothing new to store or keep in sync: the messages the agent already saves are the chat's memory, and a retry reuses the same model. | Nov 25 | Replies render with Streamdown (Shiki for code, KaTeX for math), loaded lazily in the browser and never on the server. Its own classes are off (the `sd` prefix, which Tailwind never generates), so `typeset` and `src/styles/prose.css` style it. `prepareMarkdown` rewrites math to remark-math's `$$` form, names fence languages, and holds back half-written pieces while a reply streams                                                                                                 | Streamdown is the AI SDK team's streaming renderer and replaces the archived Chat's hand-built block splitting and healing. | Nov 25 | PRs squash-merge, through GitHub auto-merge turned on by the PR's thread after Alec's go-ahead. Replaces the Nov 25 "merge commit" rule                                                                                                                                                                                                             |
