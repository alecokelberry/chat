# Decisions

Why Chat is built the way it is. Newest first; a row changes only when the decision does.

| Date   | Decision                                                                                                                                                                                                                                                                                       | Why                                                                                                                                                                                                                                                                                                              |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nov 25 | NVIDIA calls go through a Cloudflare AI Gateway, "chat", with NVIDIA as a custom provider. The AI SDK stays: the gateway is only its base URL plus a token. Logs on, caching off, a 40 requests a minute cap. The URL, the token and NVIDIA's key are Wrangler secrets                         | Free, and it shows every request with its tokens and errors against NVIDIA's unpublished free limits. The cap matches NVIDIA's own (about 40 a minute), so a runaway loop stops at the gateway. New gateways must have a token                                                                                   |
| Nov 25 | Each chat is an `AIChatAgent` named `<user id>:<chat id>`, reached at `/api/chats/<id>` (its WebSocket and `/get-messages`) through `src/server.ts` after a session check, not through `routeAgentRequest`                                                                                     | The name comes from the session, so no account can open another's chat whatever id it asks for, and nothing about ownership needs storing. Streaming runs in the Durable Object, which gets 30 s of CPU per message, not the Worker's 10 ms                                                                      |
| Nov 25 | Tests choose the mock model with `MOCK_MODEL=1`, a var like `DEV_SIGN_IN`, and build with `--mode test`, which adds ui-sdk's agent bridge for the agent test. One real-NVIDIA test, `pnpm smoke`, runs by hand                                                                                 | Tests never spend NVIDIA's rate limit or depend on it. A runtime var lets the same build run the smoke test; the bridge never ships live                                                                                                                                                                         |
| Nov 25 | Each branch gets a Worker Preview from Workers Builds, on its own `chat-preview` D1 and secrets. Passkeys belong to `alecokelberry.workers.dev`, which covers the live host and every Preview                                                                                                  | Alec reviews PRs on a real URL before merging. Durable Objects get their own storage per Preview, and nothing a branch runs touches the live database. `workers.dev` is the public suffix, so the account's subdomain is a valid rpID for all its hosts; replaces the Nov 25 "builds for other branches are off" |
| Nov 25 | A custom server entry (`src/server.ts`) loads the router, every route's component and Better Auth at startup, not on the first request                                                                                                                                                         | TanStack Start loads them lazily, so a fresh isolate's first request paid for it out of its 10 ms of CPU (live cold starts 50-270 ms). Startup has its own 1 s limit. Locally it cuts a cold `/sign-in` by about 40%                                                                                             |
| Nov 25 | Work flows through Matt Pocock's skills: grill, a spec issue, tickets, `implement` with `tdd`, `code-review` against the issue, `pr`. Emil Kowalski's and Vercel's skills cover UI and React. All come unmodified from upstream through `skills-lock.json`; `ui-sdk` links from `node_modules` | Alec is growing the app and wants one current, standard process from the start. Unmodified copies update with one command; our conventions live in AGENTS.md. Refine, the custom review skill, is gone                                                                                                           |
| Nov 25 | Cloudflare Workers Builds deploys each push to `main` with `pnpm run deploy`, on a user API token that can edit Workers and D1. Builds for other branches are off                                                                                                                              | Free (3,000 build minutes a month), no Cloudflare token in the public repo, and no Mac needed. Its default token can't touch D1. Preview links can't sign in (the passkey is bound to the main address) and would share the live database                                                                        |
| Nov 25 | `pnpm run deploy` builds, migrates, then deploys. `/setup` is turned off by replacing `SETUP_CODE` with a random one nobody knows, not by deleting it                                                                                                                                          | Migrations run before the code that needs them. `SETUP_CODE` is a required secret, and Wrangler refuses to deploy a Worker missing one                                                                                                                                                                           |
| Nov 25 | Sign-in: Better Auth's passkey plugin on D1 through Better Auth's own D1 support. The first passkey needs a one-time `SETUP_CODE` secret on `/setup`; Dev signs in with a button that exists only with `DEV_SIGN_IN=1` on localhost                                                            | Drizzle waits for the chat list, the first thing that needs it. No passwords means nothing to hash on the server (10 ms CPU), and the code lives in the URL fragment, so it never reaches the logs                                                                                                               |
| Nov 25 | Each piece comes in with the feature that needs it: styles, DESIGN.md notes, docs and tools for parts not built yet stay in the archived Chat until then                                                                                                                                       | Alec: simple first. A scaffold carrying 18,000 lines of other things was hard to review and kept files nothing used                                                                                                                                                                                              |
| Nov 25 | The repo is public, with secret scanning and push protection; secrets live only in Wrangler and GitHub secrets                                                                                                                                                                                 | Nothing secret is in the code, and GitHub's runners are free and unlimited for public repos                                                                                                                                                                                                                      |
| Nov 25 | CI runs on GitHub's runners, not the home server                                                                                                                                                                                                                                               | Nothing of this app runs at home any more, and a public repo on a self-hosted runner would let anyone's PR run code there                                                                                                                                                                                        |
| Nov 25 | pnpm 12 with `minimumReleaseAge` 7 days and `allowBuilds`                                                                                                                                                                                                                                      | Same supply-chain wait as before (npm's `min-release-age`), in pnpm's own settings. `core-js-pure`'s install script only prints a banner, so it's denied                                                                                                                                                         |
| Nov 25 | Agents SDK routes go in a custom server entry beside TanStack Start's handler (`routeAgentRequest(…) ?? handler.fetch(…)`)                                                                                                                                                                     | Proven in a spike on Nov 25: a WebSocket to an Agent echoed in dev, and the build carried the Durable Object. The Agents SDK adds about 2.4 MB (550 KB gzipped) to the Worker, inside the free 3 MB limit                                                                                                        |
| Nov 25 | Rebuilt from scratch on Cloudflare's free plan: TanStack Start on Workers, ui-sdk and Tailwind 4, AI SDK on NVIDIA, the Agents SDK (`AIChatAgent`) for chats, D1 with Drizzle, Better Auth passkeys                                                                                            | $0 and no server at home. The first Chat (Next.js, SQLite on the home server) is archived; its chats aren't carried over. Fallback if TanStack Start is shaky: React Router 7                                                                                                                                    |
